# ssc Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A CLI (`ssc`) that logs into Steam with a QR code and lists or bulk-deletes the account's Steam Cloud files without the Steam client or any game installed.

**Architecture:** Pure logic (selection, parsing, formatting, prompts, paging) lives in small static classes covered by xUnit tests. One `SteamSession` owns the SteamKit2 connection, login and reconnects; `CloudCatalog` and `CloudFiles` call the `Cloud` unified service through it. `Program.cs` wires System.CommandLine commands to those pieces.

**Tech Stack:** C# / .NET 10 SDK 10.0.404, SteamKit2 3.5.0, QRCoder 1.8.1, System.CommandLine 3.0.0, xunit.v3 4.0.3, Microsoft.NET.Test.Sdk 18.12.0, xunit.runner.visualstudio 4.0.1.

**Spec:** `docs/superpowers/specs/2026-11-12-ssc-design.md`

## Global Constraints

- Every new file starts with an SPDX header: `SPDX-FileCopyrightText: Copyright 2026 Robert Bopko` and `SPDX-License-Identifier: BSD-2-Clause` (comment syntax of the file type; files that cannot hold comments go into `REUSE.toml`).
- Target `net10.0`, `Nullable` and `ImplicitUsings` enabled, `TreatWarningsAsErrors` true.
- `dotnet` lives at `~/.dotnet/dotnet`; export `DOTNET_CLI_TELEMETRY_OPTOUT=1 DOTNET_NOLOGO=1 DOTNET_SYSTEM_GLOBALIZATION_INVARIANT=1` for every command (the WSL host has no libicu). The app itself sets `<InvariantGlobalization>true</InvariantGlobalization>`.
- State directory: `Path.Combine(Environment.GetFolderPath(Environment.SpecialFolder.ApplicationData), "ssc")`; token file `refresh_token` (two lines: account name, refresh token), Unix mode 600; QR files `qr.png` and `qr.html`, deleted after login.
- `LogOn` always uses a random non-zero `LoginID`.
- Reconnect at most 30 times per run; `TryAnotherCM` and `ServiceUnavailable` on logon mean disconnect and retry.
- The refresh token is never printed or logged.
- Appids `7` (Steam client) and `241100` (Steam Input Configs) are excluded by `--all`, allowed when named explicitly.
- Commits: single-line message, lowercase start, no co-author or tool attribution lines. Commit only, never push.

## Review Focus

- `ssc delete 730 730` or an appid in both the list and `--except`: duplicates collapse, `--except` wins over `--all`; `--except` without `--all` is a usage error. Tests in Task 1.
- A game with more than 500 cloud files: listing must page until `total_files`, and a page that returns 0 files must stop the loop instead of spinning. Tests in Task 3.
- stdin piped or redirected and no `--yes`: the prompt answers "N" without blocking. Test in Task 2.
- Corrupt or empty `refresh_token` (one line, blank lines): treated as "no saved login", falls back to QR, never throws. Test in Task 4.
- Account with no cloud files at all: `list` prints `No Steam Cloud files.`, `delete --all` prints the same and exits 0. Tests in Task 1 and Task 2.

### Task 5: Steam session and `ssc login` / `ssc logout`

**Files:**
- Create: `src/Ssc/SteamSession.cs`, `src/Ssc/Program.cs`

**Interfaces:**
- Consumes: `StatePaths`, `TokenStore`, `SavedLogin`, `QrDisplay`.
- Produces: `public sealed class SteamSession : IAsyncDisposable` with `public static Task<SteamSession> ConnectAsync(TokenStore tokens, QrDisplay qr, TextWriter log, CancellationToken ct)`, properties `SteamClient Client`, `SteamUnifiedMessages Unified`, `Cloud Cloud`, `SteamApps Apps`, `SteamID SteamId`, `string AccountName`, method `Task<string> GetWebAccessTokenAsync()` (`Client.Authentication.GenerateAccessTokenForAppAsync(SteamId, refreshToken, allowRenewal: false)`, returns the access token), and `DisposeAsync` (LogOff, wait for disconnect up to 5 s).
- Produces: `Program` root command with `login`, `logout`, `list`, `delete` subcommands; `list` and `delete` are stubs printing `not implemented` in this task.

Behavior to implement in `SteamSession` (the spike in `docs/superpowers/specs/2026-11-12-ssc-design.md` "Verified facts" is the reference):
- `CallbackManager.RunWaitCallbacks(TimeSpan.FromMilliseconds(250))` on a dedicated background thread until disposed; the public API is async on top of `TaskCompletionSource`s.
- Connected: saved login → `LogOn` with it; otherwise `BeginAuthSessionViaQRAsync`, `qr.Show` on start and on `ChallengeURLChanged`, `PollingWaitForResultAsync` inside try/catch (`AsyncJobFailedException` and `TaskCanceledException` mean the connection dropped: return and let reconnect start a fresh QR session), then `tokens.Save`, `qr.Clear`, `LogOn`.
- LoggedOn: OK → complete the connect task. `TryAnotherCM`/`ServiceUnavailable` → `Disconnect()` (reconnect follows). `InvalidPassword`, `AccessDenied`, `Expired`, `AccountLoginDeniedNeedTwoFactor`, `InvalidSignature` with a saved token → `tokens.Delete()`, write `Saved login expired, scan a new QR code.`, disconnect and reconnect into QR. Anything else → fail the connect task with `$"Steam logon failed: {Result} / {ExtendedResult}"`.
- Disconnected while not connected yet: reconnect up to 30 times, then fail with `Could not reach a Steam server after 30 attempts.`
- `login` command: connect, print `Logged in as {AccountName}.`, dispose. `logout`: `tokens.Delete()` → `Logged out.` or `No saved login.`

### Task 7: Deleting and `ssc delete`

**Files:**
- Create: `src/Ssc/CloudFiles.cs`
- Modify: `src/Ssc/Program.cs` (`delete` command)

**Interfaces:**
- Consumes: `SteamSession`, `CloudCatalog`, `Selection.Select`, `Confirmation.Ask`, `TextTable`, `Paging.CollectAsync`.
- Produces: `public sealed record DeleteResult(CloudApp App, int Deleted, int Failed, int Remaining, string? Error);`
- Produces: `public sealed class CloudFiles(SteamSession session, TextWriter log)` with `Task<IReadOnlyList<CCloud_UserFile>> ListAsync(uint appId)` (`EnumerateUserFiles`, `extended_details = true`, `count = 500`, via `Paging.CollectAsync`; non-OK result throws `InvalidOperationException($"EnumerateUserFiles {appId}: {result}")`) and `Task<DeleteResult> DeleteAppAsync(CloudApp app)`.

`DeleteAppAsync`: list → if empty return `Deleted 0, Remaining 0`; `BeginAppUploadBatch(appid, machine_name = Environment.MachineName, files_to_delete = all names)`; if OK, `ClientDeleteFile(is_explicit_delete = true, upload_batch_id)` per file, then `CompleteAppUploadBatchBlocking(batch_eresult = OK if all deletes OK else the first failure)`; if the batch was refused or any file failed, plain `Cloud.Delete` for the files still present; re-list and return counts. Exceptions are caught into `Error` so the run continues.

`delete` command: options `<appid>...` (argument, zero or more `uint`), `--all`, `--except <appid>...`, `--yes`, `--dry-run`. Flow: catalog → `Selection.Select` (usage errors exit 2 with the message) → any `Unknown` → print `Not in your Steam Cloud: {ids}. Nothing deleted.` and exit 1 → empty selection prints `No Steam Cloud files.` exit 0 → print `TextTable.Render(selected)` → `--dry-run` exits 0 → `Confirmation.Ask("Delete all cloud files of these games?", yes, !Console.IsInputRedirected, Console.In, Console.Out)` false exits 1 → per game print `{AppId} {Name}: deleted {n}` or `... FAILED ({Error or remaining count})` → summary `Done: {ok} games cleaned, {failed} failed.`; exit 0 when every result has `Remaining == 0` and no `Error`, else 1.
